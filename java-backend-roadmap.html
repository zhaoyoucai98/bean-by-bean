// 别人早就写好的 ArrayList，这一阶段的你还不能用，

class MyList {
    private String[] data = new String[10];

}

JDBC：把水引进屋里

仓库建好了，可房子和仓库之间还没有通路。你得自己扛一根水管去接——这就是 JDBC。 麻烦在于：每次用水都要自己接一次，用完还得自己拆。接了忘拆，水就一直漏——也就是 资源泄露， 漏多了整个系统就瘫了。

💡

这一幕看懂概念就行，不用练。真实项目不会手写 JDBC，但你得知道框架替你做了什么，否则出问题时无从下手。真正要记住的是一件事：数据库连接是稀缺资源——这就是连接池存在的理由。

DriverManagerConnection StatementResultSet连接池
UserDao.java · 查一次数据，手工开、手工关Java
Connection conn = DriverManager.getConnection(url, user, pwd);
Statement  st   = conn.createStatement();
ResultSet  rs   = st.executeQuery("SELECT * FROM user");
while (rs.next()) {
    System.out.println(rs.getString("name"));
}
// 三步都得手动关，少关一个就泄露：
rs.close(); st.close(); conn.close();

😫 这一阶段的痛

开连接、关连接的代码到处重复；SQL 混在 Java 代码里；忘记关闭就连接泄露。

✅ 你获得的能力

Java 终于能真正读写数据库了——这是后端开发最关键的一步通路。

SSM：零件预制好了，但说明书堆成山

有人把常用零件都预制好了：Spring IOC 帮你管零件的生产和装配，AOP 统一加装水电，SpringMVC 负责前台接待，MyBatis 接管水管。可代价是：你得写一大堆 XML 说明书 告诉它们怎么拼。说明书堆成山，一个字母写错就跑不起来。

⚠️

2026 年没人从 SSM 起步了，XML 配置千万别背（现在全用注解）。但这一幕有一个东西必须学：IOC 和 AOP 的思想——那是 SpringBoot 的地基，不懂就只能抄代码、不会排错。建议学完第 5 幕再回头看，会豁然开朗。

📌 Spring Boot 3.x（需 JDK 17+）

SpringBoot：点一下，房子自己长出来

SpringBoot 说：说明书别写了，我替你猜。想要什么功能，报个名字（ Starter） 我一并送来；自动装配 负责把零件装到位；Tomcat 服务器 直接内置，不用你另外搭。最后只留一份 application.yml 写端口和数据库地址， 点一下启动，房子连同水电脚手架一起自动立起来。

⚠️

新手最容易踩的坑：Spring Boot 3.x 起，包名从 javax.* 改成了 jakarta.*。 照着 2022 年以前的老教程抄，import 会一片红。另外它要求 JDK 17 及以上，装环境时别装错。

Starter 起步依赖自动装配 内嵌 Tomcatapplication.yml约定大于配置
App.java · 一行启动整个项目Java
@SpringBootApplication   // 一个注解 = 全套默认配置
public class App {
    public static void main(String[] args) {
        SpringApplication.run(App.class, args);  // 启动！
    }
}
application.yml · 只需要写你真正关心的YAML
server:
  port: 8080
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/demo

🤔 还缺什么？

它解决的是"搭起来慢"，但业务代码、SQL 优化、异常处理、安全防护仍要你自己写；框架黑盒变多，出了问题更难查。

// 热点数据放 Redis，数据库压力立刻降一个数量级
String val = redisTemplate.opsForValue().get("user:" + id);

从地基到小区：六个阶段对比

每一层都不是"取代"上一层，而是站在上一层之上偷懒。框架只是替你把重复劳动做了，底下的 JavaSE、SQL、HTTP 始终还在。

阶段盖房子比喻解决了什么留下的痛点你会写出的东西
① JavaSE地基、砖块水泥让你能写出能跑的程序全手写、重复多、做 Web 从零造轮子控制台小项目、算法题
② MySQL+Maven材料仓库 + 自动送货数据可持久保存；第三方库随用随取SQL 与表结构要自己设计；依赖可能冲突建表语句、pom.xml
③ JDBC手动接水管Java 终于能读写数据库开关连接代码到处重复，忘关就泄露DAO 层、手写 CRUD
④ SSM预制零件 + 说明书解耦、可维护；不再重复造轮子XML 配置繁重，一处写错就启动失败Spring 配置、Mapper
⑤ SpringBoot一体化建房套件几分钟起项目，专注业务黑盒变多、排错变难；业务与优化仍靠自己独立可运行的 Web 服务
⑥ 微服务一栋变一个小区横向扩容，扛住高并发分布式事务、一致性、排查成本高多服务 + 缓存 + 队列
